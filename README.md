# SIEM system 

This Project involves in learning how to detect, monitor, and respond to security incidents by collecting and analyzing security events and logs from various sources

# Prerequisites:
- Basic knowledge of cybersecurity principles and log analysis
- system with Elasticsearch, Logstash, and Kibana

# Required software: 
- [Elasticsearch](https://www.elastic.co/downloads/elasticsearch)
- [Logstash](https://www.elastic.co/downloads/logstash)
- [Kibana](https://www.elastic.co/downloads/kibana)
